## `wood_elements/wood_element_beam.h`

### `Beam`

A timber beam: a polyline axis with a square section of one radius per segment, joined to other beams where their axes come within reach; WoodSession::compute_axis_contacts and compute_beam_features find the pairs and cut four volume rectangles at each.

| Field | Type | Meaning |
|---|---|---|
| `ELEMENT_TYPE` | `static constexpr std::string_view` | The element_type this beam is written under. |
| `axis` | `session_cpp::Polyline` | Centreline, one segment per span, in world space. |
| `radii` | `std::vector<double>` | Section half-width per segment; a segment without one takes part in no joint. |
| `directions` | `std::vector<session_cpp::Vector>` | Section up direction per segment; a segment without one takes the contact normal. |
| `allowed_type` | `int` | Which contacts this beam accepts: 0 crossing only, 1 side-to-end and end-to-end, -1 any. |

An empty beam: no axis, no radius.

### `Plate`

A timber plate: a bottom and a top outline, one side face per edge, and the joints cut into it. It carries two geometries, as a compas_model element does: element_geometry_mesh() is the plate alone, the loft of its two outlines, never cut; model_geometry_mesh() is the plate with its joints cut in, the loft of the merged outlines, the one to inspect and the one pb_dump writes. Neither is lofted until asked for.

| Field | Type | Meaning |
|---|---|---|
| `ELEMENT_TYPE` | `static constexpr std::string_view` | The element_type this plate is written under. |
| `LEGACY_ELEMENT_TYPE` | `static constexpr std::string_view` | The element_type wood wrote before, still accepted on read. |
| `polylines` | `std::vector<session_cpp::Polyline>` | Face outlines: [0] bottom, [1] top, [2..] one closed quad per side. |
| `planes` | `std::vector<session_cpp::Plane>` | One plane per outline, normals pointing out of the plate. |
| `thickness` | `double` | Distance between the bottom and the top plane. |
| `reversed` | `bool` | True when the constructor reversed both outlines to make the bottom normal point away from the top. |
| `features` | `Features` | Merged cut outlines after compute_features; empty before. Call invalidate_geometry() after assigning. |
| `feature_types` | `std::vector<int>` | Joint type per face from the joints_types sidecar, indexed like polylines; empty lets the solver decide. The annen and vidy datasets only. |

| Field | Type | Meaning |
|---|---|---|
| `_element_geometry_mesh` | `mutable std::optional<session_cpp::Mesh>` | Cache of compute_element_geometry_mesh(). |
| `_model_geometry_mesh` | `mutable std::optional<session_cpp::Mesh>` | Cache of compute_model_geometry_mesh(). |
| `_element_geometry_brep` | `mutable std::optional<session_cpp::BRep>` | Cache of compute_element_geometry_brep(). |
| `_model_geometry_brep` | `mutable std::optional<session_cpp::BRep>` | Cache of compute_model_geometry_brep(). |
| `_geometry_synced` | `bool` | True while the Element slot holds the current model geometry. |
