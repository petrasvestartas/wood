## `wood_algorithms/wood_assignment.h`

Every plate's feature_types reset to -1 per slot (bottom, top, one per side), then each point's type written into the slot of every plate whose nearest outline segment lies within 10 x settings.distance: a negative type names the bottom or top face, a positive one the side; the absolute value is stored.

```cpp
void assign_feature_types(const std::vector<std::shared_ptr<Plate>>& plates, const Settings& settings, const std::vector<session_cpp::Point>& points, const std::vector<int>& types);
```

Every plate's insertion vectors reset to zero per slot, then each line's vector written into the side slot of every plate whose outline segment nearest the line start lies within 10 x settings.distance.


### `DetectionTrace`

What detection counted and why it gave up on a pair; filled only when a caller asks for it.

| Field | Type | Meaning |
|---|---|---|
| `coplanar` | `int` | Face pairs that passed the coplanarity test. |
| `overlapping` | `int` | Face pairs with a real overlap area. |
| `fail_reason` | `std::string` | Why the pair was rejected, under TRACE. |

Candidate element pairs (i, j) with i < j: inflated OBB per element, a BVH over their AABBs, then an OBB/OBB SAT test; `names` selects by name, empty means everything.

```cpp

```

True when two faces touch back-to-back: z axes antiparallel within `cos_angle` (cos of config::ANGLE, radians) and each origin within `coplanar_tolerance` (a squared distance) of the other's plane; the z axes need not be unit length.

```cpp

```

Largest overlap of two coplanar outlines as a closed polygon in `plane0`, via Clipper2 on the `clipper_scale` grid; areas at or below `clipper_area` are none; coplanarity is a precondition, triangles count only when `include_triangles`.

## `wood_algorithms/wood_feature_detection.h`

Classifies one plate pair as a wood joint; true fills out_joint, and out_swap_planes_1 asks the caller to flip el1. Tolerances, extensions and thresholds come from settings; `search_type` picks face-to-face, cross or both; `trace`, when given, records the counts and the reason for a rejection.

## `wood_algorithms/wood_feature_detection_beam.h`

One beam pair to one FeatureBeam: the end types at the closest points (`cross_or_side_to_end` separates a crossing from an end contact), four volume rectangles of `volume_length` from each beam's radius and up direction (`flip_male` rotates the male corners), trimmed by the cut planes of a crossing or a side-to-end. False when the end types are not allowed by either beam, a radius is missing, or a frame is degenerate.

```cpp
bool beam_to_beam(const Beam& beam0, const Beam& beam1, const ContactAxis& contact, double volume_length, double cross_or_side_to_end, int flip_male, FeatureBeam& out);
```
