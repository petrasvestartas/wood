# Settings and config

Generated by `tools/api_docs.py` from the headers; do not edit by hand.

## `wood_settings.h`

### `SearchType`

Which detection pass compute_features runs.

| Value | Code | Meaning |
|---|---|---|
| `face_to_face` | 0 | Coplanar faces: ss_e_ip / ss_e_op / ss_e_r / ts_e_p / tt_e_p. |
| `cross_joint` | 1 | Elements passing through each other: plane_to_face, type 30. |
| `face_to_face_then_cross` | 2 | Face-to-face first, cross as the fallback. |

### `Settings`

Every tunable of the solver: read from the dataset yml by config::load_yaml, held by the WoodSession that solves, passed by reference into every algorithm and joint builder, written with the scene. No algorithm reads a global.

| Field | Type | Meaning |
|---|---|---|
| `search_type` | `SearchType` | The detection pass (yml `search_type`). |
| `joint_parameters` | `std::vector<double>` | Joint-family triples [division_length (mm), shift, joint id]; families 0=ss_e_ip 1=ss_e_op 2=ts_e_p 3=cr_c_ip 4=tt_e_p 5=ss_e_r 6=b. |
| `joint_volume_extension` | `std::vector<double>` | Additive [width, height, length] extension (mm) of joint volumes: one triple for every joint type, or one per type (side-side, top-side, top-top, cross). |
| `joint_scale` | `std::array<double, 3>` | Multiplicative [sx, sy, sz] scale of joint geometry before insertion; 1 = no change. |
| `dihedral_angle` | `double` | Degrees; rotated-joint threshold. |
| `all_treated_as_rotated` | `bool` | Force the rotated geometry path. |
| `rotated_joint_as_average` | `bool` | Averaged plane for rotated joints. |
| `distance` | `double` | Inflate AABBs / point-merge tolerance (mm). |
| `distance_squared` | `double` | Squared coplanarity tolerance (mm²). |
| `angle` | `double` | Angular tolerance, radians. |
| `duplicate_points_tolerance` | `double` | Consecutive duplicate points removed when an obj is read. |
| `limit_min_joint_length` | `double` | Joints whose centreline is shorter are dropped. |
| `clipper_scale` | `int64_t` | Mm -> int64 scale for the 2D boolean (1e6 = nanometre grid). |
| `clipper_area` | `double` | Overlap areas at or below this (mm²) are not a contact. |
| `beams` | `std::vector<double>` | Beam datasets (yml `beams`): [radius, allowed joint type, min_distance, volume_length, cross_or_side_to_end, flip_male]. |
| `custom_joints` | `std::map<std::string, std::array<std::vector<session_cpp::Polyline>, 2>>` | User joint outlines per family ("ss_e_ip", "ss_e_op", "ts_e_p", "cr_c_ip", "tt_e_p", "ss_e_r", "b"): [0] male, [1] female, pairs (face0, face1). |
