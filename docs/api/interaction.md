## `wood_interaction/wood_interaction.h`

### `Interaction`

Everything between the two elements of one graph edge: where they touch, what was cut, how forces pass. The pair itself lives on the edge, whose guid is this record's key in WoodSession::interactions.

| Field | Type | Meaning |
|---|---|---|

| `contacts` | `std::vector<InteractionContact>` | Every place the pair touches. |
| `features` | `std::vector<InteractionFeature>` | Every joint cut between the pair. |
| `structure` | `std::optional<InteractionStructure>` | Empty until the structural pass exists. |

## `wood_interaction/wood_interaction_contact/wood_interaction_contact_face_type.h`

### `ContactType`

Topology class of a face contact from the two face indices alone (index < 2 outer, >= 2 side); a crossing is a ContactCross and a boundary crossing a ContactAxis, not a class here. Not FeaturePlate::joint_type: that is the solver's refined code (11/12/13/20/30/40) and needs geometry.

| Value | Code | Meaning |
|---|---|---|
| `unknown` | -1 | No plate face convention: every Block contact. |
| `side_side` | 0 | Both faces are sides; refines to 11, 12 or 13. |
| `side_top` | 1 | One side face and one outer face; refines to 20. |
| `top_top` | 2 | Both outer faces; refines to 40. |

## `wood_interaction/wood_interaction_feature/wood_interaction_feature_plate.h`

### `FeaturePlate`

A plate-to-plate joint: the pair, the face contact it was solved from, the variant the joint library built, its parameters, the cut outlines per element per face and the two element features the hosts carry. The solver builds it in place; the interaction stores it whole.

| Field | Type | Meaning |
|---|---|---|
| `guid` | `std::string` | Identity of the joint; minted by detection, the key its InteractionFeature is stored under. |
| `element_a` | `std::string` | The male element, by guid; swapped with element_b by the solver, so not ordered. index_of() gives a position. |
| `element_b` | `std::string` | The female element, by guid. |
| `contact` | `ContactFace` | Which faces touched, and where. |
| `joint_type` | `int` | Refined solver code: 11/12/13 side-side, 20 top-side, 30 cross, 40 top-top. |
| `name` | `std::string` | The joint library variant that built the outlines ("ss_e_ip_2", "side_removal"), empty before construction. |
| `cross_faces` | `std::array<int, 2>` | Cross joints only: the second side face of each element in the crossing; {-1, -1} otherwise. |
| `joint_lines` | `std::array<session_cpp::Line, 2>` | The two alignment lines, one per element, along the shared edge. |
| `joint_volumes` | `std::array<std::optional<session_cpp::Polyline>, 4>` | The volume rectangles: [0] and [1] bound the male side, [2] and [3] the female side when it differs. |
| `male_outlines` | `std::array<std::vector<session_cpp::Polyline>, 2>` | Male cut outlines per face, [0] bottom and [1] top; the last entry of each face is a 2-point endpoint marker. |
| `female_outlines` | `std::array<std::vector<session_cpp::Polyline>, 2>` | Female cut outlines per face, laid out like male_outlines. |
| `male_fabrication_types` | `std::array<std::vector<int>, 2>` | One FabricationType per male outline. |
| `female_fabrication_types` | `std::array<std::vector<int>, 2>` | One FabricationType per female outline. |
| `divisions` | `int` | Number of teeth or notches along the joint line. |
| `shift` | `double` | Lateral offset of the pattern along the joint line, 0..1. |
| `length` | `double` | Length of the joint line. |
| `division_length` | `double` | Spacing between divisions along the joint line. |
| `scale` | `std::array<double, 3>` | Multiplicative scale of the unit-box geometry, x, y, z. |
| `unit_scale` | `bool` | True when the variant pins its axial size to unit_scale_distance. |
| `unit_scale_distance` | `double` | The axial size a unit-scale variant is pinned to; 0 reads it off the volume rectangle. |
| `linked_joints` | `std::vector<std::string>` | Guids of the joints this one is linked with (three-valence shadows). |
| `linked_joints_seq` | `std::vector<std::vector<std::array<int, 4>>>` | Per linked joint, the vertex ranges merge_linked_joints interleaves. |
| `link` | `bool` | True when this joint is the link of a three-valence group. |
| `no_orient` | `bool` | True when the outlines are already in world space and must not be oriented. |
| `element_features` | `std::array<session_cpp::ElementFeature, 2>` | The joint as each host element carries it: [0] male (element_a, face_a), [1] female; bodies current only after sync_features(). |
| `feature_guids` | `mutable std::array<std::string, 2>` | Identity of the two sides, minted on first read; kept here because an ElementFeature copy drops its guid. |
